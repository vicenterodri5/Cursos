# 📖 Sobre el repositorio

Este repositorio reúne diferentes **cursos, clases, actividades, proyectos y recursos educativos**.

Cada curso se desarrolla de manera independiente, pero mantiene una estructura común para facilitar su organización, consulta y reutilización.

El repositorio está pensado para crecer progresivamente con nuevos cursos y contenidos.

---

# 🎯 Propósito

El objetivo es crear una biblioteca de cursos que permita:

* 📚 Organizar contenidos educativos.
* 🧠 Facilitar el aprendizaje.
* 💻 Integrar herramientas tecnológicas.
* 🤖 Incorporar Inteligencia Artificial cuando sea pertinente.
* 🧪 Promover el aprendizaje práctico.
* 🚀 Desarrollar proyectos.
* 🌎 Compartir conocimiento.
