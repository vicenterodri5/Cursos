# 📖 Sobre la materia

**Informática Contemporánea** es una materia diseñada para comprender la informática desde una perspectiva actual.

La informática ha dejado de limitarse al uso tradicional de una computadora. Actualmente integra:

**Inteligencia Artificial + Programación + Electrónica + Automatización + Robótica + Creatividad**

Esta materia busca que el estudiante conozca estas tecnologías, experimente con ellas y posteriormente las utilice para desarrollar una **solución tecnológica física**.

---

# 🎯 Objetivo

Desarrollar en los estudiantes las competencias necesarias para:

* Comprender la informática contemporánea.
* Utilizar herramientas de Inteligencia Artificial.
* Formular instrucciones efectivas para modelos de IA.
* Generar texto, imágenes, video y audio mediante IA.
* Comprender el funcionamiento de los agentes de IA.
* Utilizar programación y electrónica.
* Diseñar prototipos.
* Automatizar procesos.
* Resolver problemas mediante tecnología.
* Trabajar colaborativamente.
* Presentar y defender un proyecto tecnológico.

# 🚀 Proyecto tecnológico

Durante la segunda mitad del curso, cada equipo desarrollará un **proyecto tecnológico físico**.

El proyecto deberá comenzar con una problemática real y terminar con un prototipo funcional.

# 🤖 Inteligencia Artificial

La Inteligencia Artificial será una herramienta transversal durante toda la materia.

Los estudiantes aprenderán a utilizar diferentes tipos de IA:

| Tecnología        | Aplicación                              |
| ----------------- | --------------------------------------- |
| 📝 IA de texto    | Investigación, escritura y programación |
| 🎨 IA de imágenes | Diseño y visualización                  |
| 🎬 IA de video    | Comunicación y demostraciones           |
| 🎙️ IA de audio   | Narración, voz y contenido              |
| 🧠 Agentes de IA  | Automatización y ejecución de tareas    |

### ⚠️ Regla fundamental

> **La IA puede ayudarte a hacer algo, pero debes ser capaz de explicar qué hizo, cómo lo hizo y por qué funciona.**

La finalidad no es aprender a depender de la IA.

La finalidad es aprender a **trabajar con ella**.
